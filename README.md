# TON Gift Terminal Pro — Telegram Бот + Mini App для NFT та Подарунків 💎

Повноцінний автономний комбайн для аналітики, снайпінгу, арбітражу, оферів та розумного продажу (**Auto-Undercut**) Telegram Gifts і TON NFT у чистому **біло-синьому дизайні TON**.

Працює з живими даними **Portals API**, **Getgems API**, **TonAPI** + підтримка підключення **MRKT**, **Tonnel** і **Fragment**.

---

## 🚀 Швидкий запуск (Windows)

### Варіант 1 — В 1 клік (PowerShell)
```powershell
.\start.ps1
```
Скрипт автоматично створить `.env` (у безпечному режимі `DRY_RUN=True`), збере Mini App і запустить сервер на **`http://127.0.0.1:8000`**.

### Варіант 2 — Вручну
```bash
# 1. Створи конфіг (базові живі дані Portals/Getgems/TonAPI працюють одразу БЕЗ ключів!)
cp .env.example .env

# 2. Встанови Python-залежності (якщо потрібно)
pip install -r requirements.txt

# 3. Збери фронтенд Mini App
cd frontend
npm install
npm run build
cd ..

# 4. Запусти Backend + Mini App + Telegram Bot
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

Відкрий **`http://127.0.0.1:8000`** у браузері — Mini App готовий до роботи!

## 🤖 Як підключити свого Telegram Бота + Mini App у Telegram

1. Напиши `@BotFather` → `/newbot` → отримай **TG_BOT_TOKEN**.
2. Дізнайся свій Telegram ID через `@userinfobot` → це твій **TG_ADMIN_CHAT_ID**.
3. Встав ці дані у файл `.env` **АБО** прямо у вкладці **`⚙️ Маркети`** всередині Mini App і натисни **«Зберегти налаштування»** → **«Перевірити зв’язок з ТГ»**.
4. Для запуску Mini App всередині Telegram потрібен HTTPS URL (наприклад через `ngrok http 8000`, Cloudflare Tunnel або VPS):
   - Пропиши URL у `WEBAPP_URL` в `.env` (або в налаштуваннях).
   - У боті команда `/start` автоматично покаже кнопку **«📱 Відкрити TON Gift Terminal»**.

### Команди Telegram Бота:
- `/start` — головне меню, кнопка запуску біло-синього Mini App та швидкі дії (`Топ фліпи`, `Арбітраж`, `Портфель`).
- `/xray Eternal Rose #18718` (або просто скинь у чат посилання `https://t.me/nft/EternalRose-18718`) — миттєвий рентген NFT із фото, Fair Value, флором колекції та моделі, останніми продажами і чистим профітом.
- **Інлайн-кнопки під кожним алертом:** `[🛒 Купити]` `[⚡ Поставити офер]` `[📊 Історія продажів]` `[📱 Відкрити в Mini App]`.
- **Алерти Auto-Undercut:** якщо конкурент перебив твою ціну, бот шле миттєве повідомлення з кнопками `[✅ Знизити на -0.05 TON]` / `[❌ Залишити]`.

## 📱 5 робочих сторінок Mini App (нижня панель)

1. **`🔍 Сканер`** — живий потік лотів з фільтрами (колекція, маркет, мінімальний дисконт %, тільки рідкісні комбо, миттєвий пошук по моделі/фону/#номеру) + горизонтальна стрічка **Крос-маркет Арбітражу**. При кліку на будь-який NFT відкривається повний **X-Ray Drawer** із калькулятором фліпу, флором кожного трейта, порівнянням 4 маркетів та історією продажів.
2. **`📊 Аналітика`** — миттєвий **X-Ray Оцінювач**, інтерактивні графіки **TradingView Lightweight Charts** (`24h / 7d / 30d`), таблиця флорів по Моделях/Фонах/Символах, глибина стакану (Orderbook Depth), теплова карта колекцій (Heatmap), детектор накрутки (Wash-Trade) та **Трекер Китів**.
3. **`🎯 Снайпер`** — конструктор правил снайпера (колекція, модель, фон, макс. ціна, мін. дисконт %, режим `Алерт в ТГ` або `Автобай`), **Радар Оферів** (Bid-Ask спреди + перебивання в 1 клік `+0.1 TON`) та **Журнал Алертів** із прев’ю Telegram-картки.
4. **`💼 Портфель`** — PnL-дашборд твоїх активів, **Smart Auto-Undercut** (автоматичне або з підтвердженням зниження ціни на `-0.05 TON` під конкурента із жорстким захистом `Мін. ціна`), **Захист Тонкого стакану** (попереджає не демпінгувати перед стрибком ціни) та порадник найкращого маркету для продажу.
5. **`⚙️ Маркети`** — підключення TON гаманця, статус і ключі/сесії для Portals / Getgems / MRKT / Tonnel / Fragment, налаштування Telegram Бота та ліміти ризику (`DRY RUN`, денний ліміт витрат, макс. ціна угоди, стоп-лос).

## 🛡️ Безпека
- За замовчуванням увімкнений **`DRY_RUN=True`** — усі покупки та автобаї симулюються без витрат реальних TON, поки ти сам не перемкнеш режим.
- **Захист мінімальної ціни (`min_price_guard`)** в Auto-Undercut гарантує, що бот ніколи не скине твій NFT нижче заданого порогу, навіть якщо конкурент демпінгує в мінус.
- **Захист тонкого стакану** зупиняє зайвий демпінг, коли перед різким ростом ціни залишилось 1–2 лоти.
